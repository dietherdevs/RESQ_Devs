# Color Replacement Guide

## Blue Color Updates (Lighter Blue Theme)

### Gradient Backgrounds
- `bg-gradient-to-r from-blue-600 to-blue-800` → `bg-gradient-to-r from-blue-400 to-blue-500`
- `bg-gradient-to-b from-blue-600 to-blue-800` → `bg-gradient-to-b from-blue-400 to-blue-500`

### Solid Backgrounds
- `bg-blue-600` → `bg-blue-500`
- `bg-blue-700` → `bg-blue-600`
- `bg-blue-800` → `bg-blue-600`
- `bg-blue-900` → `bg-blue-700`

### Hover States
- `hover:bg-blue-700` → `hover:bg-blue-600`
- `hover:bg-blue-800` → `hover:bg-blue-600`

### Text Colors
- `text-blue-600` → `text-blue-500`
- `text-blue-700` → `text-blue-600`  
- `text-blue-800` → `text-blue-600`
- `text-blue-900` → `text-blue-700`

### Border Colors
- `border-blue-500` → `border-blue-400`
- `border-blue-600` → `border-blue-400`
